# Changelog

All notable changes to this project. Format: Keep a Changelog 1.1.
Versions follow Semantic Versioning. The tags v0.1, v0.5 and v1.0 were
cut before portfolio standard v2 and are kept as they are; under the
standard no release has been made yet.

## [Unreleased]

### Changed
- 2026-11-08: Restructured to the portfolio standard v2. README is the
  abstract (question, headline with its interval, field, job family,
  verdict). Verdict: Functional, not pre-registered. PROPOSAL.md
  replaces SPEC.md, NOVELTY.md, DOSSIER.md and the Build and Deep
  specs, and adds a confirmatory re-run plan (draft, not locked).
  REPORT.md replaces the three level READMEs, ROADMAP.md (now "Future
  work") and docs/research-review.md. Code moved to src/, question sets
  to experiments/, recorded results to results/ (regenerated byte for
  byte). fanout/ and PUBLICITY.md moved to docs/fanout/. docs/index.md
  removed (its text duplicated the README).
- 2026-11-08: Grades and review scores removed from public files; they
  are kept internally.
- 2026-11-08: CI runs with read-only permissions, adds the layout test,
  and fails if results/ does not regenerate unchanged. CodeQL covers
  Python and JavaScript; Dependabot watches the site's npm packages.

### Added
- 2026-11-08: docs/decisions 0001 to 0003, CITATION.cff, SECURITY.md,
  tests/test_layout.py (required files, no public grade).
- 2026-11-07: Research review: uncertainty (seeded bootstrap, exact
  McNemar), leakage probe, sensitivity sweep; now in REPORT.md.
- 2026-11-07: Live dashboard on GitHub Pages: a browser port of the
  Build and Deep pipelines, with a parity gate against the recorded
  results.

## [1.0] - 2026-11-04 (pre-standard tag)

### Added
- Compressed Deep: deterministic query rewriting, a lexical HyDE
  simulation and bridge-term multi-hop retrieval, measured on 42
  labelled questions; 17 tests (52 total).
- Fan-out drafts (blog, tutorial, website copy, LinkedIn draft, paper
  brief, release notes) and the Actions pack (CI matrix with ruff,
  CodeQL, Dependabot, release, labeler, greetings, stale).

## [0.5] - 2026-11-04 (pre-standard tag)

### Added
- Build: hybrid BM25 plus TF-IDF retrieval with reciprocal rank
  fusion, a coverage and F1 reranker and a query API, measured on 24
  labelled questions over a 20-document corpus; 20 tests.

## [0.1] - 2026-11-04 (pre-standard tag)

### Added
- Learn: TF-IDF retrieval with cited extractive answers over a
  6-document corpus, 8 labelled questions; 15 tests.
